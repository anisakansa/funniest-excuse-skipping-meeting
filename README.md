# The Funniest Excuse for Skipping a Meeting (Round 2)

One razor-sharp line that gets you out of a pointless meeting:

> My manager asked me to skip this meeting so I could finish the work this meeting was called to discuss.

Round 1 finished 926 of 1,562 — this round 2 line takes a different, sharper angle: the meeting itself is what blocks the work, and the boss said so.

## Run

```sh
node main.ts
```

Writes the line to `output/entry.txt` (103 characters, deterministic — two runs produce byte-identical output).
